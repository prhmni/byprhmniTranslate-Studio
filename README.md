## ✨ Fitur Utama

- **100% Offline & Privat:** Seluruh inferensi bahasa diproses lokal di mesin komputer tanpa mengirim teks ke API server luar.
- **Dua Arah Sekaligus:** Menerjemahkan bolak-balik English ↔ Bahasa Indonesia dengan tombol swap instan.
- **Optimalisasi Kualitas Kalimat:** Menggunakan **Beam Search (5-Beams)** untuk menghasilkan terjemahan yang lebih luwes dan kontekstual.
- **Antarmuka Modern SaaS:** Dilengkapi fitur Text-to-Speech (suara audio), riwayat sesi lokal (*local storage*), salin cepat, dan unduh hasil `.txt`.
- **Desain Responsif:** Tampilan adaptif otomatis untuk layar desktop maupun ponsel pintar.
